## Brand & Style

This design system targets users seeking absolute privacy, rigorous record-keeping, and distraction-free document management. The visual language marries Notion’s tranquil, editorial minimalism with Airtable’s data-dense, mechanical precision, calibrated specifically for native Windows desktop ergonomics.

The overall aesthetic is structured, rational, and quiet:
- **Calm Visual Simplicity:** Elimination of non-functional decoration, oversized radii, deep drop-shadows, and bright gradients.
- **High-Density Utility:** Strict horizontal and vertical alignment designed for rapid keyboard entry, dense scanning, and tabular organization.
- **Local-First Serenity:** The interface projects permanence, stability, and zero visual friction, prioritizing immediate legibility and content-over-chrome framing.

## Colors

The palette is engineered for prolonged operational focus on desktop monitors, eliminating eye strain through soft foundation tones and disciplined accenting.

- **Canvas & Surfaces:**
  - Application Window Chrome & Shell Background: `#F3F5F6`
  - Primary Work Surface, Data Grids & Modals: `#FFFFFF`
  - Subtle Row Hover & Neutral Highlight: `#F8FAFA`
- **Typographic Neutral Hierarchy:**
  - Primary Content & Table Data: `#263238`
  - Secondary Metadata, Column Headers & Captions: `#69777D`
  - Inactive / Disabled States: `#A0ACB0`
- **Borders & Grids:**
  - Structural Borders, Dividers & Matrix Lines: `#DCE3E5` (crisp 1px solid rendering)
  - Focused Element / Active Cell Border: `#298F89`
- **Accent & Selection:**
  - Accent Primary: `#298F89` (balanced teal for active indicators, primary triggers, and checkboxes)
  - Selection Fill: `#E6F4F3` (low-saturation pale teal for selected rows, multi-cell blocks, and active sidebar items)
- **Functional States:**
  - Error: `#D32F2F`
  - Warning: `#E68A00`
  - Success / Verified: `#2E7D32`

## Typography

The type system relies on `Segoe UI` (with native fallback to `system-ui, sans-serif`), ensuring optimal subpixel text rendering, complete Cyrillic glyph harmony, and instant font loading in desktop environments.

- **Data Density Baseline:** The default reading and data input baseline is anchored at `13px` (`body-md`), preserving legibility across dense rows without wasting vertical pixels.
- **Headers and Attributes:** Column headers and form metadata use `label-sm` (11px, medium weight, subtle tracking) in `#69777D` to create clear hierarchical distinction against input values.
- **Code & Serial Numbers:** Where raw keys, checksums, or file hashes are shown, the monospaced token (`JetBrains Mono`, 12px) is used to guarantee tabular figure alignment.

## Layout & Spacing

The layout is built around a rigid shell structure optimized for desktop utility and keyboard navigation.

- **Application Shell Architecture:**
  - **Top Titlebar & Utility Strip:** 36px fixed height, containing window controls, breadcrumb directory status, and quick search.
  - **Collapsible Master Sidebar:** 
    - Expanded: Fixed `190px` width.
    - Collapsed / Icon Rail: Fixed `56px` width.
  - **Secondary Action Toolbar:** 38px fixed height directly above active views for view-switching, filter chips, and sorting controls.
- **Main Workspace / Grid Layout:**
  - Content pane fills 100% of the remaining horizontal and vertical viewport (`calc(100vh - 74px)`).
  - No artificial margin bands around primary data grids; data tables pin edge-to-edge against their containing panels.
  - Form dialogs and inspector drawers adhere to compact 8px/12px padding intervals.

## Elevation & Depth

Visual hierarchy is communicated via clean structural lines and tonal shifts rather than floating drop shadows:

- **Surface Tiers:**
  - Level 0 (Window Frame & Sidebar): `#F3F5F6`
  - Level 1 (Primary Data Panes, Sheets, Inspector): `#FFFFFF`
  - Level 2 (Flyouts, Dropdowns, Date Pickers): `#FFFFFF` accompanied by a precise `0 4px 12px rgba(38, 50, 56, 0.08)` perimeter shadow to prevent visual bleed into underlying content.
- **Grid & Edge Definition:**
  - Dividers, panel splits, and spreadsheet cells strictly use `1px solid #DCE3E5`.
  - Nested groups and row separators avoid double-border compounding through shared collapsed borders (`border-collapse: collapse`).
- **Focus Indicators:**
  - A crisp 1px inner or outer outline in `#298F89` without blur indicates active cell and keyboard focus rings.

## Shapes

The design system employs a soft, technical corner philosophy (`roundedness: 1` = 2px to 4px) tailored to dense desktop interfaces:

- **Buttons, Inputs, and Badges:** `3px` corner radius.
- **Flyout Menus, Context Menus, and Modal Dialogs:** `4px` corner radius.
- **Table Cells and Grid Containers:** `0px` (completely square) to ensure contiguous boundary rendering and pixel-perfect line intersection.
- **Tabs and View Switches:** Segmented rails with `2px` internal active indicator rounding.

## Components

### Buttons & Triggers
- **Height:** Compact 30px standard, 26px for inline grid-cell actions.
- **Primary:** Background `#298F89`, text `#FFFFFF`, hover `#237A75`, border `none`.
- **Secondary / Ghost:** Background `transparent`, text `#263238`, border `1px solid #DCE3E5`, hover background `#F3F5F6`.
- **Icon Buttons:** 28x28px square, 3px radius, text/icon `#69777D`, hover background `#E6F4F3` with `#298F89` icon color.

### Form Inputs & Editable Cells
- **Text Fields:** 32px height, 1px solid `#DCE3E5`, background `#FFFFFF`, text `#263238`, placeholder `#A0ACB0`. Focus switches border to `#298F89` with zero shadow.
- **Data Table Cells:** 30px row height. Default state displays unbordered text; hovering highlights row with `#F8FAFA`; double-click or enter transitions directly into an inline active editor with a `#298F89` 1px inset border.

### Checkboxes & Radio Controls
- **Size:** 14x14px with 2px radius for checkboxes; 14x14px circular for radio buttons.
- **State:** Unchecked has 1px solid `#69777D` border; checked fills with `#298F89` with a crisp white tick.

### Status Chips & Tags
- **Dimensions:** 20px height, 3px radius, 6px horizontal padding, `11px` typography.
- **Variants:**
  - Verified / Valid: Background `#E8F5E9`, text `#2E7D32`.
  - Warning / Incomplete: Background `#FFF3E0`, text `#E68A00`.
  - Error / Failed: Background `#FFEBEE`, text `#D32F2F`.
  - Neutral Category: Background `#F3F5F6`, text `#263238`, border `1px solid #DCE3E5`.

### Data Grid (Airtable-style Table)
- **Header:** 32px height, `#F3F5F6` background, uppercase `11px` `#69777D` text, draggable column divider lines in `#DCE3E5`.
- **Row:** 30px height, zebra striping avoided in favor of crisp horizontal `#DCE3E5` gridlines and hover row state `#F8FAFA`.
- **Selection:** Selected cells or multi-rows adopt `#E6F4F3` background tint with an active bounding border of `#298F89`.

### Sidebar Navigation
- **Item Height:** 30px with 6px horizontal icon padding.
- **Active State:** Background `#E6F4F3`, text `#298F89`, font weight `600`, with a 3px left indicator bar in `#298F89`.
